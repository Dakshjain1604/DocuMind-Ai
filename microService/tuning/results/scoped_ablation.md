# Scoped retrieval ablation

Eval set: `microService/tuning/eval_set.jsonl` (40 questions, real gold chunk ids from a 535-page technical book, generated by an LLM from randomly sampled chunks). Chunking fixed at chunk_size=1000, chunk_overlap=150 (matching how the eval set's gold_chunk_id values were assigned). Each stage adds exactly one pipeline capability on top of the previous one; stage 4 matches the app's production retrieval config (RRF weights, rerank mode, multi-query count) at the time of this run.

| Stage | Recall@5 | Recall@10 | Recall@15 | MRR | nDCG@10 | Avg latency (ms) |
|---|---|---|---|---|---|---|
| 1. Vector-only (naive RAG baseline) | 0.100 | 0.150 | 0.325 | 0.064 | 0.049 | 754 |
| 2. + hybrid fusion (vector + BM25 + graph, RRF) | 0.225 | 0.325 | 0.400 | 0.162 | 0.116 | 16 |
| 3. + cross-encoder rerank | 0.375 | 0.375 | 0.400 | 0.336 | 0.178 | 391 |
| 4. + multi-query rewrite (full production config) | 0.425 | 0.425 | 0.450 | 0.352 | 0.194 | 1088 |
